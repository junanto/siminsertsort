Simulasi Insertion Sort

Belajar mengurutkan data dengan proses memilih, membandingkan, menggeser, dan menyisipkan.

1. Masukkan Data

Gunakan 3–10 bilangan. Bilangan boleh berulang.

2. Simulasi

Klik Mulai, kemudian gunakan tombol Langkah Berikutnya untuk melihat proses Insertion Sort.

3. Algoritma yang Digunakan

for setiap elemen mulai dari elemen kedua:
  ambil elemen sebagai KEY
  bandingkan KEY dengan elemen sebelumnya
  selama elemen sebelumnya lebih besar:
    geser elemen sebelumnya ke kanan
  sisipkan KEY pada posisi yang tepat

4. Tantangan Analisis

Pertanyaan:
1. Pada iterasi mana terjadi pergeseran paling banyak?
2. Mengapa elemen yang sedang diproses dapat dibandingkan dengan beberapa elemen sebelumnya?
3. Jika data sudah hampir terurut, apakah jumlah pergeseran cenderung lebih sedikit? Jelaskan.
4. Apa perbedaan strategi Insertion Sort dengan Selection Sort?
